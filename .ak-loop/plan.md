# Plan and what was actually done

## Plan followed
1. Read AGENTS.md, CONTRIBUTING.md; npm is the package manager.
2. Baseline: `ak-docs index` and `ak-docs doctor`: grade B 76, connectivity 8%
   (23/349 areas), benchmark not-analyzed, four missing package docs.
3. Connectivity: give each registry/<id>/README.md a `docbridge.covers`
   entry for its own `area:registry/<id>`. Build strips that front matter so
   bundles keep the original README text.

   their relative links, and point the generator's agentDoc routes at them.
   Declare covers only for targets that resolve (not area:docs, area:catalog,
   area:validation, which are unresolved).
5. Benchmark: docs/bench/retrieval-suite-v1.json, 26 cases, generated by a
   helper script. Improve titles and summaries where the right page missed.
6. Guard test scripts/retrieval-suite.test.mjs.
7. Regenerate config, README standard source hash, index, bundles.

  install 2.4.2 and could not write its lockfile. Everything was verified with
  the installed 2.4.0 binary.
- Portuguese cases were not added: the maintained docs are English only.
- Three misses are left unfixed (see the PR body).
- check:readme-standard fails on the expired reviewDueOn date. reviewedOn and
  reviewDueOn were not changed, per the contract.

  #173/#174 cover overlapping work and bump doc-bridge to 2.5.0). `git rebase` is
  not allowed in this sandbox, so the branch was not rebased. See
  .ak-loop/hitl/ for the decision this needs.
- .doc-bridge/ (index, llms.txt, capabilities) is git-ignored here, so it is not a tracked artifact.
